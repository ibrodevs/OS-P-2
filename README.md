## Цель работы

Закрепить работу с Bash-скриптами и системными вызовами Linux: обработать журналы, реализовать параметры командной строки и сравнить накладные расходы `cat` и Python-программы через `strace`.

## Что реализовано

- `report.sh` считает `ERROR`/`WARN` по модулям и поддерживает `--top N`;
- есть валидация аргументов и существования каталога;
- `hello.py` читает файл и выводит его размер;
- `run_analysis.sh` запускает `strace` и сохраняет результаты;
- выполнено прямое сравнение системных вызовов `cat` и `python3 hello.py`.

## Запуск

```bash
chmod +x report.sh run_analysis.sh
./report.sh logs ERROR
./report.sh --top 2 logs WARN
python3 hello.py test.txt
./run_analysis.sh
```

## Ключевые результаты

На приложенном тесте получено:

| Программа | Системных вызовов |
|---|---:|
| `python3 hello.py test.txt` | 571 |
| `cat test.txt` | 121 |

С исследуемым `test.txt` в Python непосредственно связано **8 системных вызовов**. Большая разница с `cat` объясняется запуском интерпретатора Python, загрузкой библиотек и модулей, работой с памятью и инициализацией среды выполнения.

## Вывод

Высокоуровневая программа на Python удобнее для разработки, но её запуск требует значительно больше системных вызовов, чем специализированная утилита `cat`. `strace` позволяет увидеть эти накладные расходы на уровне взаимодействия программы с ядром Linux.
